# OMNIX-Entropy 0.2.0

这是从规则基础层到 Computer Agent 决策深化的统一功能版本，重点是扩大诊断覆盖，同时继续把真实操作限制在可确认、可审计和可回滚的本地安全管线内。

## 本次改进

- 新增独立实现的 Winapp2 兼容规则基础层，可解析、校验和预览社区清理规则；OMNIX 不捆绑第三方规则库。
- 新增社区规则中心和只读 Rule Lab，规则导入、HTTPS 下载、版本切换和回滚都绑定来源、许可证、版本与 SHA-256，并要求明确确认。
- 社区规则匹配会先经过 OMNIX 自己的保守策略，只把完整、低风险、旧的缓存文件提升为安全预览候选。
- 符合条件的精确文件可在确认后进入隔离区，并在后悔药中心查看时间线和还原；规则警告、注册表目标、脚本意图和高风险位置保持只读。
- C 盘体检扩展了旧安装包、浏览器缓存、开发工具缓存、Windows 诊断、临时文件和其他主要占用来源，并避免重复累计相互包含的空间线索。
- 应用管理会把同名版本、便携副本、更新载荷和数据线索放在一个应用家族里解释，但卸载、迁移和缓存操作仍只绑定一条精确记录。
- 干净卸载继续先使用官方卸载器，再按风险扫描残留；低风险残留进入隔离区，高风险或身份不明内容不会自动处理。
- 安装管控支持 MSI、Inno、NSIS、Burn 和未知安装器识别、D 盘优先路径建议、用户规则记忆及安装后变化报告。
- 迁移结论会分别说明主程序、缓存、模型、下载和用户数据，迁移后继续观察原 C 盘位置，避免把“程序在 D 盘”误说成“以后不再写 C 盘”。
- Computer Agent 新增网络、声音、蓝牙或外设、屏幕、驱动或设备、蓝屏或重启等新手故障分流。
- Agent 可以回答 C 盘为什么还满、最近谁增长最快、怎样安全释放指定空间、多个同名应用哪个能卸载，以及为什么程序在 D 盘但缓存仍在 C 盘。

## 安全边界

- 社区规则不提供脚本执行权，不直接修改注册表，也不会静默下载或后台自动清理。
- 路径、规则、应用身份、文件状态或快照发生变化时，旧方案会失效并停止，而不是猜测后继续执行。
- 清理、卸载残留、迁移、自启动和系统修改仍必须经过本地 `OperationPipeline` 的证据、风险、确认和回滚检查。
- 低风险文件处理默认进入隔离区，不永久删除；高风险操作缺少快照或回滚时会拒绝执行。
- Computer Agent 使用本地摘要回答，不能直接删除、迁移、卸载、禁用服务、修改注册表或运行安装器。
- 本版本不会静默安装，不会自动接受 UAC，也不会修改 Windows 证书信任、安全软件或 SmartScreen 设置。

## 发布状态

版本号和源码已准备为 0.2.0；只有完成 CI、个人签名、安装包独立验证、草稿资产回下载校验和 GitHub Release 后，已安装版本才会在软件内发现这一更新。
