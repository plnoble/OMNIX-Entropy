# OMNIX-Entropy 0.1.1

这是面向个人 Windows 电脑的首次公开安装版。

## 本次更新

- 应用管理新增更直观的 Windows 系统足迹结论，可识别软件在右键菜单、资源管理器、浏览器连接和文件关联中的存在。
- 系统足迹只做有边界的只读扫描，并优先使用安装路径或完整应用名关联，避免仅凭厂商关键词下结论。
- 应用抽屉继续只展示普通用户能理解的结论，具体注册表位置保留在技术详情中。
- Computer Agent 会解释软件还会出现在哪里，并给出观察建议；本版本没有新增直接删除、禁用或修改注册表的权限。
- 安装器默认建议安装到 `D:\Software\OMNIX-Entropy\Install`，始终显示目录选择，不支持静默安装。

## 安全说明

- App、Elevated Worker、安装器和卸载器使用同一个 OMNIX-Entropy Personal Publisher 签名。
- GitHub Release 同时提供安装器清单、更新通道清单和 SHA-256 校验文件。
- 个人发布证书不提供公开 SmartScreen 信誉，Windows 仍可能显示提示。
- 本次发布构建和验证不会运行安装器，也不会改动现有安装。
