# OMNIX-Entropy 0.1.2

这是补全软件内更新闭环的修复版本。

## 本次更新

- 发现新版本后，更新窗口会显示“下载并安装”，不再只能打开 GitHub 发布页。
- 更新包保存到当前 OMNIX 安装目录旁边的 `Updates` 目录，继续遵守 D 盘优先原则。
- 下载过程严格限制为发布清单记录的文件大小，并核对 SHA-256。
- Windows 发布者签名必须有效，且必须同时匹配发布清单和当前正在运行的 OMNIX。
- 下载完成后会再次复核文件；真正启动安装器前还会重新检查，防止文件在等待期间被替换。
- 安装器启动必须经过明确确认和 `OperationPipeline`，不支持静默参数，不会替用户点击安装。
- 安装器打开后，当前 OMNIX 会退出，以便安装程序替换旧版本文件。

## 第一次使用说明

0.1.0 和 0.1.1 本身只有检查更新能力，不能获得尚未安装的新更新代码。因此需要从 GitHub 发布页手动下载并安装一次 0.1.2。安装 0.1.2 后，后续版本即可使用软件内的“下载并安装”流程。

## 安全说明

- 下载成功不等于允许运行；大小、哈希、可信签名和同发布者证据缺一不可。
- 更新包只允许暂存到非系统盘的 OMNIX 受管目录。
- 校验失败不会启动安装器，未验证的暂存目录会被清理。
- 更新不会修改证书信任、关闭安全软件或绕过 Windows 安全提示。
- 安装过程仍是可见、交互式的，安装位置和最后确认由用户决定。
