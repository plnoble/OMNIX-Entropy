# OMNIX-Entropy 0.1.4

这是磁盘体检体验改进版本。

## 本次改进

- 体检入口可以选择 C、D 或其他已就绪的本地固定磁盘，不需要手动输入路径。
- 系统盘继续使用 Windows 专项诊断；数据盘只按空间来源和个人文件候选进行只读分析，不会把普通文件夹判断成系统垃圾。
- 首页会给出明确的 80% 舒适目标、已确认低风险空间、剩余差额和一个 Agent 下一步。
- 首页关键发现和体检历史现在可以独立滚动，较长结果不会被卡片裁掉。
- 切换磁盘、重新扫描、取消或失败时会清空旧方案，避免把上一块磁盘的结论当成当前证据。
- 数据盘建议不再要求把文件移动到同一块磁盘；系统健康历史仍只记录系统盘体检。

## 安全边界

- 磁盘扫描和 Agent 改善方案默认只读。
- Agent 可以选择一项低风险建议供你查看，但不会替你确认或执行。
- 清理仍需显示证据、风险、预计影响和回滚方式，并经过本地 `OperationPipeline`。
- 本版本没有新增自动删除、自动迁移、服务修改、注册表修改或静默安装能力。

## 发布状态

版本号和源码已准备为 0.1.4；只有完成签名、安装包验证和 GitHub Release 后，已安装版本才会在软件内发现这一更新。
