# OMNIX-Entropy 0.1.3

这是安装目录与更新提示修复版本。

## 本次修复

- 安装器不再通过“浏览”按钮把 `Install` 自动追加两次。
- 默认安装目录仍是 `D:\Software\OMNIX-Entropy\Install`，目录选择页面继续可见。
- 如果 OMNIX 位于不受支持的目录结构，更新窗口会明确说明安装位置不正确，并提示重新安装到受管目录。
- 安装布局不正确时不会下载更新包，也不会启动安装程序。
- GitHub 发布页无法打开时，更新窗口会保留在当前程序内并给出可重试提示。

## 从 0.1.2 更新

安装在 `D:\Software\OMNIX-Entropy\Install` 的 0.1.2 可以使用软件内的“检查更新”和“下载并安装”升级到 0.1.3。

如果 0.1.2 仍位于 `D:\Software\OMNIX-Entropy\Install\Install`，它会继续安全拒绝应用内更新，需要从 GitHub 发布页手动安装 0.1.3。

## 安全边界

- 本版本没有新增清理、迁移、卸载、服务、启动项或注册表修改权限。
- 更新包仍必须通过固定 GitHub 来源、大小、SHA-256、有效 Windows 签名和同发布者验证。
- 启动安装器前仍需用户明确确认，并经过本地 `OperationPipeline`。
- 安装程序保持可见和交互式，不使用静默安装参数。
