# OMNIX-Entropy 0.1.5

这是 C 盘结论和应用管理决策改进版本。

## 本次改进

- C 盘改善方案会比较“安全可处理空间”和“回到 80% 舒适目标还差多少”，小清理不会再冒充主要解决办法。
- 首页和磁盘页面会先引导查看真正占空间的应用、个人文件和增长来源，同时保留低风险清理作为可选动作。
- 新增用户临时文件、崩溃转储、DirectX 着色器缓存、Windows 临时文件和更新缓存等已知位置的只读盘点。
- 系统缓存会明确标为“交给 Windows 清理”；检测到体积不等于允许手动删除。
- 应用管理会把同一软件的不同版本、安装位置和数据线索放在一起解释，但不会合并卸载。
- 应用抽屉会说明当前选中的是哪个版本、有没有官方卸载入口，以及卸载只针对哪一条记录。
- 迁移结论会分别说明当前程序能释放多少、同类程序或更新载荷还在 C 盘多少、C 盘数据是否仍会继续增长。
- C 盘来源列表改为自动换行和纵向滚动，不再依赖横向滚动查看长结论。

## 安全边界

- 已知临时和系统缓存目前只提供体积证据与处理建议，不会自动删除。
- 没有官方卸载入口的副本或更新载荷不会出现可执行卸载按钮。
- 同类应用只用于解释；卸载、迁移、缓存和自启动操作仍绑定到当前选中的精确应用记录。
- 清理、卸载残留、迁移和系统修改仍需经过证据、风险、确认、隔离区或回滚检查，并由本地 `OperationPipeline` 控制。
- 本版本没有新增静默安装、自动清理、自动卸载、自动迁移、服务修改或注册表修改能力。

## 发布状态

版本号和源码已准备为 0.1.5；只有完成 CI、签名、安装包验证和 GitHub Release 后，已安装版本才会在软件内发现这一更新。
